# DES-2025-2026-SpainEasy

## 📌 Descripción del proyecto

SpainEasy es una aplicación diseñada para ayudar a estudiantes extranjeros en España a gestionar y comprender mejor los trámites administrativos, como el empadronamiento, la solicitud del TIE, la búsqueda de alojamiento y otros procesos burocráticos.

A través de esta aplicación, los usuarios pueden crear un perfil personalizado, seguir una ruta de trámites, consultar información gratuita, solicitar ayuda presencial y utilizar herramientas basadas en inteligencia artificial.

El objetivo principal del proyecto es facilitar el proceso de adaptación administrativa de los estudiantes internacionales y reducir las dificultades relacionadas con la burocracia en España.
